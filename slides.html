02 | Description Technique

🏗️ Architecture Découplée (MVC)

  • Séparation Client / Serveur : Découpage strict pour une modularité maximale.
  • Front Controller : Le fichier backend/index.php centralise et route toutes les requêtes.
  • Échanges JSON : Communication standardisée via des endpoints REST HTTP.

03 | Méthodologie

🔄 Organisation & Étapes du Projet

  • Étape 1 - Modelisation : Conception du schéma SQL et règles de gestion des matches.
  • Étape 2 - API Backend : Développement des contrôleurs (UserController, MatchController, MessageController).
  • Étape 3 - Client Web : Intégration HTML/CSS et contrôleurs JS modulaires.
  • Étape 4 - Validation & Diagnostics : Scripts d'audit et vérification de la syntaxe.
💡
Approche Modulaire
Chaque fonctionnalité principale (Authentification, Dashboard, Messagerie, Admin) dispose de son contrôleur et modèle dédié aussi bien côté Backend que Frontend.
03 | Méthodologie

🔐 Sécurité & Robustesse du Système

Protection des Données
  • Mots de passe : Hachage fort via l'algorithme BCrypt (password_hash()).
  • Injections SQL : Éliminées à 100% grâce au binding PDO.
  • Protection XSS : Échappement des sorties côté client.
Authentification OTP & Logs
  • Vérification Email : Code à 6 chiffres généré à l'inscription.
  • Classe Logger : Journalisation centralisée des erreurs critiques et événements de sécurité dans app.log.
